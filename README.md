## Про проект

Хочу нанять себе ментора, проведу анализ рынка менторов, будупредсказывать цены менторов(если они пишут по договоренности) и найду самого выгодного по направлению


## Файлы, используемые в проекте:

- **my_research (1).ipynb** - Jupyter-ноутбук c данными по менторам. Чистка данных, визуализация, и ML. 
- **my_parser.ipynb**- Jupyter-ноутбук для парсинга сайта про менторов https://getmentor.dev
- **mentors_data.xls** - csv по менторам
